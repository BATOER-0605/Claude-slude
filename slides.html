情報漏洩対策が十分であるか

API 商用契約では「デフォルトで学習利用なし」が保証されています
🔒

学習利用：デフォルトでなし

API 法人契約（商用）では、入力データはモデルのトレーニングに一切使用されません。個人向けサービスとは明確に区別されたポリシーです。

📅

データ保持：標準 7 日で自動削除

2025 年 9 月以降、API の標準ログ保持期間は 7 日間。必要な場合は Data Processing Addendum（DPA）により 30 日保持をオプトイン可能です。

🛡️

Zero Data Retention（ZDR）

Anthropic の承認を受けたエンタープライズ利用者は、入出力データを一切保存しない契約（ZDR）を締結できます。最高水準のデータ保護を実現。

区分 学習への利用 データ保持期間 ZDR 対応
個人向け（Free / Pro / Max） オプトイン制（デフォルト OFF） 30 日 ✗
API 直接契約（商用） デフォルトで使用しない 7 日（標準） ✓（要申請）
Vertex AI 経由 使用しない（Commercial Terms 適用） Google 側のポリシーに依存 —

管理者による利用状況の可視性

Enterprise プランでは組織全体の活動を一元管理できます Enterprise 限定
📋

監査ログ（Audit Logs）

  • ユーザー操作・システムイベントの全記録
  • データアクセスの追跡
  • 内部統制・コンプライアンス対応
🔌

Compliance API

  • 会話履歴・ファイルへのプログラムアクセス
  • 活動ログのエクスポート
  • 社内コンプライアンスシステムとの連携
📊

Analytics API

  • 組織全体の利用統計の集計
  • 部門別・ユーザー別コスト分析
  • ROI 測定・経営レポート作成
💰

支出上限設定

  • ユーザー単位の利用上限設定
  • 組織全体の予算管理
  • 予期せぬコスト増加を防止
※ 上記機能はすべて Enterprise プラン のみ対応。Team プランでは管理コンソールの基本機能（メンバー管理・請求確認）のみ利用可能です。

アカウント管理のしやすさ

IdP 連携による自動プロビジョニングで管理コストを最小化

SAML SSO（シングルサインオン）

Okta・Microsoft Entra ID（旧 Azure AD）など主要 IdP と連携。会社アカウントで統一ログイン管理が可能。Team プランは Google / Microsoft 限定。

SCIM プロビジョニング

入社・退社・異動時のアカウント作成・削除・権限変更を IdP と同期して自動化。手動オペレーション不要でミスを防止。

ドメインキャプチャ

会社ドメインのメールアドレスを持つユーザーを自動的に組織アカウントに割り当て。個人アカウントでの利用（シャドー IT）を排除。

機能 Team プラン Enterprise
SSO（シングルサインオン） Google / Microsoft 限定 SAML 対応
SCIM（自動プロビジョニング） ✗ ✓
ドメインキャプチャ ✗ ✓
最低席数 5 席〜 20 席〜（セルフサーブ）
支払い方法 クレカ・ACH（USD） 請求書払い・多通貨対応
カスタムデータ保持期間 ✗ ✓
HIPAA 対応 / BAA ✗ ✓（セールス経由）

業務の自動化および自律実行

API からマルチエージェントまで、段階的な自動化に対応
⚙️

Claude API

  • 自社アプリへの AI 機能組み込み
  • 社内 RPA・ワークフローとの連携
  • 文書処理・分類・要約の自動化
  • Python / TypeScript / Java SDK 対応
💻

Claude Code（CLI）

  • ターミナルから自律的にコード生成
  • テスト作成・リファクタリング・デバッグ
  • Git 連携で PR 作成まで自動化
  • VSCode / JetBrains 拡張機能あり
🔗

MCP（ツール連携）

  • 外部システム・DB からのデータ取得
  • Slack / GitHub / Jira などへの操作
  • ブラウザ操作・コンピューター使用
  • 独自ツールのプロトコル実装も可能
🤖

マルチエージェント

  • オーケストレーター＋サブエージェント構成
  • 複数タスクの並列・分散処理
  • 長時間・複雑な業務フローの自律実行
  • Claude Agent SDK で構築可能
活用例：　市場レポートの収集→要約→Slack 投稿の完全自動化　／　コードレビューの自動化　／　社内 FAQ への自律応答エージェント　／　データ分析レポートの定期生成

利用方法の全体像

目的に応じた 4 つのアクセス方法
💬
Team / Enterprise

claude.ai チャット

ブラウザからすぐに使えるチャット UI。文書作成・調査・アイデア出しなど幅広い業務に対応。Projects 機能で知識を蓄積・共有できます。

⌨️
Team / Enterprise / API

Claude Code CLI

ターミナルで動作する AI コーディングエージェント。コードの自律生成・テスト・デバッグ・PR 作成まで対応。エンジニアの生産性を大幅に向上。

🖥️
Team / Enterprise / API

VSCode 拡張機能

Visual Studio Code に Claude Code を統合。エディタを離れず AI によるコード補完・解説・リファクタリングが可能。JetBrains IDE にも対応。

🔧
API / Vertex AI

API 統合

社内システム・Web アプリ・自動化ツールに Claude を組み込む。Anthropic 直接 API または Vertex AI 経由で利用可能。SDK は複数言語対応。

Claude Code の利用要件： Team / Enterprise プランに加え、API アクセスが必要です（使用量は別途 API 料金として課金）
Vertex AI 経由の場合： 機能の一部がプレビュー提供となる場合があります。GCP のセキュリティ・監査ログを活用したい場合に有効な選択肢です
